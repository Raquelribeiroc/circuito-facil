GUIA RÁPIDO

Como usar o Circuito Fácil

  1. Use os menus do simulador.
    O CircuitJS1 tem menus próprios para adicionar fontes, resistores, diodos, transistores, capacitores e fios.
  2. Conecte os terminais.
    Os componentes precisam estar eletricamente conectados, não apenas próximos visualmente.
  3. Observe o comportamento.
    O simulador pode mostrar correntes animadas, tensões e gráficos, dependendo do circuito.
  4. Salve ou exporte pelo próprio motor.
    Use os comandos disponíveis no menu do CircuitJS1. O salvamento próprio do Circuito Fácil ainda será desenvolvido.

Esta interface é uma camada visual experimental. Ela não substitui validação profissional nem deve ser usada, sem verificação, para garantir segurança de circuitos físicos.
